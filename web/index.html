Magic Pockets port — real ground collision

Every level now collides against its own real geometry, not the old synthetic pink test arena: the actual per-tile ground-collision table (6de3:f189, referenced but never dumped since Phase 3) was read directly out of the binary, and it's a clean, real solid/passable/special classification indexed by the exact on-disk tile value — see web/core/tile-collision.js and docs/engine.md. Spawn point, pickups, and the exit are found by scanning this real collision for standable spots (still not the game's actual authored positions — that data isn't recoverable from level files alone — but always inside real, walkable geometry now). The player also renders as a real sprite from its confirmed character bank (cap + sunglasses), not an orange box -- a hand-verified representative pose (an earlier attempt landed on a genuinely empty tile and silently rendered nothing; see docs/port-plan.md's "Follow-up fix" entry for how that was found and fixed). Enemies whose sprite addressing IS resolved (most of them) already rendered real sprites since Phase 1; the rest still fall back to a dot. Audio (Phase 7) and world/level flow (Phase 6) are unchanged. See docs/port-plan.md.
