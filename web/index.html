Magic Pockets port — Phase 3 checkpoint

Entity simulation: pick your local, unmodified data/ folder (still RNC-ProPack-compressed, exactly as shipped). A player entity (the orange box) walks, jumps, is blocked by/lands on the pink-outlined collision geometry, and can break the block directly ahead of it — arrow keys/WASD to move + jump, space/ctrl to break a block. Every other level-script entity is spawned into a 146-slot pool (matching the original's real entity capacity) and rendered, but doesn't act yet — no behavior/script VM wiring until Phase 4. The pink collision grid is a hand-authored placeholder, not derived from the real cave art underneath — while building this phase it turned out every real .pap cell is non-zero (no usable "empty" marker), and the actual per-tile solidity table ([0xef23], confirmed to exist but not yet dumped) is a genuinely open item — see web/engine/placeholder-terrain.js, the updated docs/engine.md, and docs/port-plan.md.
