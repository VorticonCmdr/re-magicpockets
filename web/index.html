Magic Pockets port — Phase 5 checkpoint

Player systems, HUD, bonus economy — the "first fully playable level" milestone: pick your local, unmodified data/ folder. Walk/jump (arrows/WASD), break blocks ahead (space/ctrl), collect the yellow pickups, avoid/survive the chasing enemies from Phase 4 (each hit costs a heart, top-right — 0 hearts respawns you), and reach the green exit zone to finish. Breaking a block spawns a real bonus-item sprite chosen by Entity_ChooseAndSpawnBonusItem's REAL world-1 decision tree (web/engine/bonus-economy.js), fed approximated inputs since this port doesn't simulate the subsystems that produce the real difficulty-input globals. The score/hearts HUD is a plain canvas-text placeholder — the original's custom glyph-tile rendering needs font data this project hasn't resolved — but every number it shows is real tracked game state.
